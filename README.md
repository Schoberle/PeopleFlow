# PeopleFlow

## 📌 Sobre o projeto

O **PeopleFlow** é um sistema web desenvolvido para auxiliar na gestão de colaboradores, permitindo o cadastro, visualização, edição e organização das informações dos funcionários.

O projeto foi desenvolvido como parte da disciplina de **Projeto de Software**, utilizando uma arquitetura com Frontend, Backend e Banco de Dados.

---

## 🎯 Objetivo

Desenvolver uma aplicação web para facilitar o gerenciamento das informações dos colaboradores, centralizando os dados em um sistema integrado.

---

## 🚀 Funcionalidades — AC1

Na primeira etapa do projeto, foi desenvolvida a funcionalidade de gerenciamento e visualização de colaboradores.

### Funcionalidades implementadas:

- Cadastro de colaboradores
- Listagem de colaboradores
- Visualização dos dados de um colaborador
- Edição dos dados de um colaborador
- Integração entre Frontend, Backend e Banco de Dados
